# 🚦 [AI-Pass] 강화도 PoC Headless AI 단속 엔진 기획안 (V3.0)



**문서 상태:** 🟡 **검토 대기 (팀장 승인 후 즉시 구현 전환)**

**목적:** 영상 서빙(Streaming) 역할을 Web 파트로 이관하고, AI 파트는 오직 '강화대교 1개 채널의 초정밀 과속 단속 및 데이터 전송'에만 100% 자원을 집중하는 Headless 아키텍처 구축.



## 1. 핵심 아키텍처 개편 방향 (Headless AI)

FastAPI 서버는 더 이상 브라우저와 직접 통신하거나 화면(UI)을 그리지 않습니다. 오직 백그라운드에서 영상을 씹어 삼키고(Ingest), 위반 데이터를 정제하여 Web 백엔드로 쏘아주는 **보이지 않는 심장(Event Producer)** 역할만 수행합니다.



* **[폐기]** `GET /api/v1/cameras/thumbnails` 등 11개 서브 카메라 접속 및 캡처 워커 전면 백지화.

* **[폐기]** MJPEG 스트리밍 라우터 및 시각화용 OpenCV `cv2.putText/rectangle` 렌더링 로직 제거 (연산량 극대화).

* **[집중]** 오직 강화대교(1채널) RTSP만 수신하여 AI 추론(YOLO) 및 물리 연산 수행.



## 2. 코어 분석 엔진 설계 (Core Logic)

화면 렌더링에 낭비되던 CPU 자원을 온전히 단속 알고리즘의 신뢰도 향상에 투입합니다.



1. **초정밀 속도 산출 (Homography + EMA):**

   * 카메라 렌즈의 원근 왜곡을 펴주는 **호모그래피(투시 변환)**를 적용하여 실제 도로(m) 기준의 좌표를 확보합니다.

   * 바운딩 박스 떨림(Jitter)을 잡기 위해 **지수이동평균(EMA, Exponential Moving Average)** 필터를 적용하여 순간 튀는 속도(Spike) 오탐을 완벽히 필터링합니다.

2. **모의 LPR (Mock LPR) 파이프라인:**

   * 과속(`80km/h` 이상 등 설정값 초과) 판정 시, 해당 객체에 대해 더미 번호판 이미지(Base64)와 가상의 OCR 텍스트(예: `123가4567`)를 즉시 매핑합니다.

3. **즉각적인 JSON 발송 및 GC (메모리 해제):**

   * 이벤트가 완성되는 즉시 비동기 HTTP 클라이언트(`httpx`)를 통해 Spring Boot 서버(`POST /api/violations`)로 JSON 페이로드를 발송합니다.

   * 전송이 완료된 객체의 이력(History)은 가비지 컬렉터(GC)를 통해 즉시 메모리에서 파기하여 OOM(Out of Memory)을 방어합니다.
