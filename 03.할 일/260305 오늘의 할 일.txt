이 프로젝트의 핵심은 자동차 번호인식 // 주문프로세스의 깔끔함 // 관리자 페이지의 화면들

키오스크(주문프로세스) > 실제 커피만드는 부분(DB에서만 작업) > 출하(DB 작업완료)

그래서 일단은 키오스크 부분먼저 해봐요
맨처음 부분
관리자는 어떤 화면을 넣어야 할지 생각만 이거는 생각만
가장 중요한건 키오스크 핵심



기술 융합 역량 증명: 비전공자로서 6개월간 학습한 Web(Spring Boot, Vue) 기술과 AI(Computer Vision, NLP, Machine Learning) 기술을 성공적으로 융합한 풀스택 프로젝트 완성.

MSA(Microservice Architecture) 경험: Java(Spring Boot) 메인 서버와 Python(FastAPI) AI 서버를 분리하여 설계하고, RESTful API를 통한 통신 및 데이터 처리 파이프라인 구축.

MVP(Minimum Viable Product) 달성: 차량 진입부터 주문, 결제, 그리고 관리자의 설비 모니터링까지 이어지는 핵심 시나리오가 실제 구동 가능한 수준으로 구현.



본 프로젝트는 4차 산업혁명의 핵심 기술(인공지능, 빅데이터)을 일상적인 '드라이브 스루 카페' 도메인에 적용하여, 완전 무인화 및 자동화된 서비스를 제공하는 시스템입니다.


주요 기술 테마
YOLOv8 및 PaddleOCR을 활용한 실시간 차량 번호판 인식.
MediaPipe를 활용한 비접촉 제스처(Hand/Pose) 입력.
OpenAI Whisper를 활용한 자연스러운 음성 주문 처리.
센서 데이터를 분석하여 고장을 사전에 예측하는 예지보전(Predictive Maintenance) 모델 구축.


요구사항 정의 및 아키텍처 설계: 프론트엔드(Vue) - 메인 서버(Spring Boot) - AI 서버(FastAPI) 간의 명확한 역할 분담 및 API 명세서(Swagger 등 활용) 작성.
모듈별 병렬 개발: 웹 서비스 파트와 AI 모델 파트로 나누어 개발을 진행하고, 빠른 주기(Agile)로 통합 테스트 진행.
포트폴리오화: 기술적 의사결정 과정, 트러블슈팅(특히 서로 다른 언어/프레임워크 간 연동 시 발생한 문제 해결 과정)을 GitHub Wiki 및 기술 블로그에 상세히 기록.
